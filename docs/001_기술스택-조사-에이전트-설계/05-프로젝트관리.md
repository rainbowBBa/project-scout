## uv 워크스페이스가 보안 경계를 강제한다

두 패키지를 워크스페이스 멤버로 쪼갠다. 이건 형식이 아니라 **핵심 요구를 물리적으로
강제하는 장치**다.

- `scout` 패키지 의존성에 `httpx`가 **없다** → 앱이 인터넷에 직접 나가려면 import 자체가 실패
- `scout-net-mcp` 패키지 의존성에 `langchain`이 **없다** → 서버가 앱 로직을 끌어올 수 없다
- `uv sync --package scout-net-mcp` 로 서버만 단독 설치 → 사내 DMZ 배포가 그대로 이 명령

**"규율로 지킨다"가 "설치가 안 된다"로 바뀌는 게 요점이다.**

## Python 버전은 uv가 관리한다

`.python-version`에 `3.12`, `requires-python = ">=3.12,<3.13"`.
`uv sync`가 3.12를 알아서 내려받는다.

시스템에 3.14.7이 깔려 있어도 무관하고, pydantic-core 등 네이티브 확장의 3.14 휠 유무를
걱정할 필요가 없다. 시스템 파이썬은 건드리지 않는다.

## ruff — 인터넷 격리를 lint 규칙으로 자동화

"`scout/`에서 httpx 직접 사용 0건"을 손으로 grep하지 않고 규칙으로 만든다.
워크스페이스 의존성 분리가 1차 방어, 이게 2차 방어다 — 표준 `urllib`을 쓰는 경우를 잡는다.

```toml
# packages/scout/pyproject.toml
[tool.ruff.lint]
extend-select = ["TID251"]

[tool.ruff.lint.flake8-tidy-imports.banned-api]
"httpx".msg          = "scout는 인터넷에 직접 나가지 않는다 — mcp_client를 쓴다"
"requests".msg       = "동일"
"urllib.request".msg = "동일"
```

루트 공통 설정:

```toml
[tool.ruff]
line-length = 100

[tool.ruff.lint]
extend-select = ["I", "UP", "B", "SIM", "RUF"]
```

`ruff format`으로 포매팅까지 한 도구로 끝낸다. black·isort·flake8을 따로 두지 않는다.

## ty — 게이트로 쓰지 않는다

`ty`는 아직 프리뷰다. 2일짜리 프로토타입에서 타입체커와 씨름하는 건 손해이므로
**정보 제공용으로만 돌리고 CI 게이트로 걸지 않는다.** 오탐이 많으면 그날 바로 끈다.

특히 확인할 점: **`ty`가 Pydantic 모델을 제대로 이해하는지.** `schemas.py`가 코드의 중심이라
여기서 오탐이 쏟아지면 값이 없다. M0에서 30초 만에 판별된다
([07-검증](07-검증.md) 확인 항목 4번).

## 명령 4개

```
uv sync                           # 전체 설치 (Python 3.12 자동 조달)
uv sync --package scout-net-mcp   # MCP 서버만 단독 설치 (배포 리허설)
uv run ruff check --fix . && uv run ruff format .
uv run ty check                   # 정보용
uv run pytest
```

실행 시 규모 플래그:

```
uv run scout run "..."                          # 기본: 요소 3개 · 후보 8~10개
uv run scout run "..." --max-components 8 --max-candidates 5   # 풀 규모
```

`uv`에 태스크 러너는 없으니 Makefile / just는 추가하지 않는다 — 4줄이면 README로 충분하다.

```toml
[dependency-groups]
dev = ["ruff", "ty", "pytest", "pytest-asyncio"]
```

**`uv` 자체 설치가 Day 1의 첫 작업이다** (현재 미설치):

```
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```
